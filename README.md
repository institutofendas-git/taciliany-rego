# Taciliany Rêgo

Site profissional estático, com HTML, CSS e JavaScript em `index.html`.

Endereço definitivo: https://taciliany.com.br/

## Publicação

GitHub Pages: publicar a branch `main`, pasta `/ (root)`. Domínio personalizado: `taciliany.com.br` (também registrado no arquivo `CNAME`). Manter HTTPS obrigatório quando disponível.

## Ao receber na conta taciliany

1. Aceitar a transferência enviada pelo GitHub.
2. Conferir em Settings → Pages: branch `main`, pasta raiz e domínio `taciliany.com.br`. Se a publicação estiver desativada, reativá-la; aguardar o deploy e o certificado, então manter Enforce HTTPS marcado.
3. No Registro.br, após a transferência ser concluída, alterar somente o CNAME de `www` de `institutofendas-git.github.io` para `taciliany.github.io`. Não incluir o nome do repositório nesse destino.
4. Preservar os quatro registros A do domínio raiz: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`.
5. Conferir https://taciliany.com.br e https://www.taciliany.com.br após a atualização do DNS.

O apontamento de www permanece no proprietário atual até a transferência ser aceita. Os metadados de compartilhamento usam o domínio definitivo, sem depender do proprietário do repositório. Layout e textos aprovados foram preservados.

O site ainda mantém a instrução `noindex, nofollow` e o robots.txt da etapa de prévia; liberar indexação é uma decisão separada.
